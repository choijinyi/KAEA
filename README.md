# 📖 말씀 낭독 — 성경 읽어주는 앱

"**마태복음 1장**"처럼 입력하면 **개역개정** 성경 본문을 찾아 화면에 보여주고,
**구글 제미나이(Gemini) TTS**의 자연스러운 여성 목소리로 읽어 주는 웹앱입니다.

## 사용 방법

1. 검색창에 `마태복음 1장`, `창세기 1장`, `시편 23장`처럼 입력하고 **찾기**를 누릅니다.
   - 약칭도 지원합니다: `마 1장`, `창 1`, `요 3장`, `고전 13장` 등
2. **⚙️ 설정**에서 본인의 Gemini API 키를 입력합니다.
   - [Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 발급받을 수 있습니다.
   - 키는 서버로 전송되지 않고 **사용자의 브라우저(localStorage)에만 저장**되며,
     Google 음성 합성 API 호출에만 사용됩니다.
3. **🔊 읽어주기**를 누르면 장 전체를 구간별로 이어서 낭독합니다.
   - 일시정지/이어서/정지, 목소리 선택(여성 6종), 현재 읽는 절 하이라이트 지원
   - 이전 장 / 다음 장 버튼으로 이어서 들을 수 있습니다.
4. **💾 MP3 저장**을 누르면 장 전체 낭독을 MP3 파일로 다운로드합니다.
   - 이미 들은 구간의 음성은 다시 합성하지 않고 재사용합니다 (같은 장·같은 목소리 기준).
   - 파일 이름 예: `마태복음 1장 (개역개정).mp3`

## 동작 방식

- **본문**: 서버 라우트(`/api/bible`)가 대한성서공회(bskorea.or.kr) 개역개정(GAE)
  페이지를 가져와 절 단위로 파싱합니다. 결과는 하루 동안 캐시됩니다.
- **음성**: 브라우저에서 `gemini-2.5-flash-preview-tts` 모델을 직접 호출합니다.
  장 전체를 약 1,100자 단위 구간으로 나눠, 현재 구간을 재생하는 동안 다음 구간을
  미리 합성해 끊김을 줄입니다. (PCM 24kHz → WAV 변환 후 재생)
- **MP3 저장**: 합성된 PCM 구간들을 이어붙여 브라우저에서 lamejs로
  MP3(96kbps mono)로 인코딩해 다운로드합니다. 서버를 거치지 않습니다.

## 실행 방법

```bash
npm install
npm run dev
```

환경 변수는 필요 없습니다. API 키는 각 사용자가 앱 화면에서 직접 입력합니다.

## Vercel 배포

저장소를 Vercel에 연결하면 Next.js 프로젝트로 자동 인식되어 배포됩니다.
별도의 환경 변수 설정이 필요하지 않습니다.

## 기술 스택

- Next.js 15 (App Router) · React 19 · Tailwind CSS 4
- Google Gemini 2.5 Flash TTS (음성 합성)
- @breezystack/lamejs (브라우저 MP3 인코딩)
- 대한성서공회 개역개정 (본문 출처)
